# MeetSpot 评测基准（第一版）

状态说明：

- 已验证：有自动化测试或本地/线上实测记录支撑
- 待验证：需要有效 LLM key 或线上环境后补测

| 编号 | 场景 | 输入要点 | 期望结果 | 状态 |
|---|---|---|---|---|
| 1 | 三人聚餐 | 3 个北京地址，咖啡馆，安静 | 返回推荐、评分依据、地图页，耗时合理 | 已验证（线上实测） |
| 2 | 复杂需求触发 Agent | 4 个地址，3 种场所，2 个需求 | 复杂度不低于 40，走 Agent 模式，失败自动降级 | 部分验证（降级已实测，Agent 成功待有效 key） |
| 3 | 单个地址解析失败 | 2 个正常地址 + 1 个乱码 | 请求不中止，明确提示跳过地址 | 已验证（单测 + 本地 E2E） |
| 4 | 全部地址解析失败 | 2 个乱码地址 | 明确错误与输入建议 | 已验证（单测） |
| 5 | POI 无结果回退 | 小众关键词，周边无结果 | 类别回退并提示，或扩大半径 | 已验证（单测） |
| 6 | 大学简称 | 北大、清华 | 正确解析到北京对应校区 | 已验证（geocode 直连） |
| 7 | 同名跨城 | 陈村地铁站 | 归佛山顺德，不误选肇庆陈村 | 已验证（geocode 直连 + 选择逻辑单测） |
| 8 | 多关键词合并 | 咖啡馆 + 餐厅 | 并发搜索、去重、合并推荐 | 已验证（单测） |
| 9 | 跨城多地点 | 北京 + 佛山 | 不做强制同城纠正，按实际城市计算 | 已验证（单测：1:1 跨城不纠正、城市提示跳过、多数同城纠正异常点） |
| 10 | 国际英文场景 | 英文地址 | Google 地理编码与 POI 归一化 | 待验证（需线上 Google key 实测） |

运行方式：`pytest tests/ -v` 覆盖第 3 至 8 项的行为测试；其余项按样例输入输出.md 手动验证并记录。

## 评测方法

1. 自动化测试：`./venv/bin/python -m pytest tests/ -q`，全部通过视为行为基线无回归
2. 稳定性测试：对基准场景第 1、2、6、7 项各连续执行 5 次，记录每次返回的 success、mode、耗时与推荐数量，结论一致性写入 docs/EVALUATION.md 或样例输入输出.md
3. 人工验证：按样例输入输出.md 的输入发起请求，核对结果页地图、推理链、评分依据是否完整
4. 线上复测：部署后使用有效 DeepSeek key 对场景 2 与场景 10 复测，记录 Agent 模式耗时与稳定性
