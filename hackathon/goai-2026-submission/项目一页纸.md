# MeetSpot 项目一页纸

版本：v1.0（2026-08-07）

## 基本信息

- 项目名称：MeetSpot 多人会面公平决策智能体
- 赛道：无界应用（Boundless Agents），自拟细分场景：本地生活服务的多人线下协作决策
- 开源协议：MIT
- 代码仓库与线上 Demo：仓库为 MeetSpot，线上地址 https://meetspot-irq2.onrender.com/

## 目标用户与核心问题

朋友聚会、学生社团、企业团建、异地客户约见和远程团队线下碰面的组织者。多人约见时地点选择耗时且众口难调，地图工具按个人位置就近返回，缺乏公平性和全局视角。

## 方案概述与核心流程

输入多方位置与需求，完成五步闭环：地址解析、公平中心计算、POI 检索、多因子评分、可解释推荐。按复杂度路由在规则模式与 Agent 模式间选择，支持多轮调整。

## Agent 架构与关键能力

- 复杂度路由与规则/Agent 双模式
- ReAct Agent：geocode、calculate_center、search_poi、generate_recommendation 四工具
- 规则评分与 LLM 语义评分双通道，五步推理链可解释
- 失败分支可解释：单个地址失败跳过并提示，POI 无结果逐级回退

## 数据来源、工具调用与技术路线

高德与 Google 地图 API 做地理编码和 POI 检索，DeepSeek（OpenAI 兼容接口）做评分；地址文本不留存，结果页自动清理。技术栈 FastAPI、SQLAlchemy 2.0、Docker，CI 含 pytest 与 ruff。

## Demo 运行结果

- 线上实测：3 个北京地址 12.4 秒返回 6 家咖啡馆，含评分与地图
- 本地实测：部分失败提示、Agent 超时降级、预算筛选（20 候选筛至 18）均通过
- 测试 43 个全绿，lint 全绿

## 安全合规边界

只接收地址文本，商业 API 依赖如实披露，推荐结果仅供参考，不替代专业判断；高德 Web key 不返回前端。

## 开放与复用贡献

公平中心计算、评分引擎、需求解析可拆分为独立组件；中英文档、API 文档、部署说明齐全；GitHub 523 星、58 fork。

## 后续计划与对接需求

企业会议规划模式（批量地址、预算约束、行程说明）、多轮协商升级、结果导出与日历集成、国际化扩展。
