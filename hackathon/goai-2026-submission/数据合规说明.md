# MeetSpot 数据来源与合规说明

版本：v1.0（2026-08-07）

## 数据类型与来源

- 用户输入：参与者的地址文本、场所偏好（关键词）、特殊需求（如安静、停车、预算）
- 地图数据：地址解析与 POI 检索来自高德地图 Web 服务 API（国内）与 Google Maps Platform（国际英文场景）
- 模型服务：评分与推荐理由生成使用 DeepSeek（OpenAI 兼容接口，默认 deepseek-v4-flash）
- 城市数据：data/cities.json 内置 50 个精选城市，用于城市推断与 SEO 页面

## 处理方式

- 地址文本仅用于本次请求的地理编码、公平中心计算与 POI 检索，不进入业务数据库
- 地理编码与 POI 结果缓存在进程内存中，缓存上限分别约 30 条与 15 条，进程重启即清空
- 推荐结果 HTML 文件包含地址与坐标，写入 workspace/js_src 目录，最多保留 50 份后自动清理旧文件
- 免费额度按 IP 记录当日使用次数，仅用于配额计数，不包含地址或推荐内容

## 授权与边界

- 用户提交地址即视为授权用于本次推荐请求
- 推荐结果仅供参考，不替代用户、组织者或专业机构的最终判断
- 本项目不涉及金融、教育、医疗、工业安全等高风险决策场景

## 第三方依赖披露

| 依赖 | 用途 | 类型 | 说明 |
|---|---|---|---|
| 高德地图 Web 服务 API | 地理编码与 POI 检索 | 商业 API | 需申请 key，国内场景必用 |
| Google Maps Platform | 英文场景地理编码与 POI | 商业 API | 按需配置，key 建议在 GCP 控制台限制 referer |
| DeepSeek | 大模型评分与推荐理由 | 商业 API | 默认 deepseek-v4-flash，OpenAI 兼容，可替换其他兼容端点 |

替换路径：模型服务可通过环境变量切换 base_url 与模型；地图服务可在高德与 Google 之间按语言路由。

## 密钥管理

- 密钥通过部署环境变量或 config.toml 配置，不提交仓库
- 高德后端 Web key 不通过 /api/config/amap 返回给前端（2026-08-07 已修复）
- 前端地图使用独立的 JS API key 与安全密钥
